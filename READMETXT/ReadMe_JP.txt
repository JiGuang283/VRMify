Model-To-VRM

MMD の PMX モデルを VRM 1.0 / 0.x に変換し、Unity（UniVRM）、VSeeFace など VRM 対応のソフトやゲームに読み込めるようにします。
FBX / unitypackage、uemodel、psk / pskx、xps は一度 PMX に変換してから VRM にできます。

対応する変換：
PMX → VRM（1.0 / 0.x）：ボーン、表情、MToon マテリアル、SpringBone 物理（1.0 のみ）
FBX / unitypackage → PMX
uemodel → PMX
psk / pskx → PMX
XPS → PMX

使い方：
1. ModelConvert.exe を実行
2. ファイルをドロップするか、ドロップ欄をクリックして選択。ドロップは読み込みとプレビューだけで、「変換開始」を押すと変換します。
3. 「タスク」は既定で拡張子から自動判定：.pmx は VRM に、その他の形式は PMX に変換します。
4. 「VRM」タブで VRM のバージョン（1.0 / 0.x）を選べます。
5. 変換後は「3D プレビュー（three-vrm）」で確認：モーション、物理、ライト、表情がアプリに読み込んだときと同じに見えます。

---------------------------

注意事項：

- Unity / ゲームへの読み込みが止まる：たいていは不正なデータです。アプリのログは
  %USERPROFILE%\AppData\LocalLow\<会社名>\<製品名>\Player.log にあり、具体的なエラーが記録されています。
- 顔が白っぽい・影がない：VRoid などネイティブ VRM の顔はもともとほぼベタ塗りで、影は主に髪の落ち影（ピンク）です。
  3D プレビューのライト角度と影の切り替えで確認できます。
- 髪 / スカートの揺れや突き抜け：物理は近似換算です。脚を大きく上げるとスカートと太ももの付け根が少し重なりますが、
  ネイティブモデルでも同様です。Unity に読み込んだ後、UniVRM の SpringBone で揺れものごとに調整できます。
- 穴あき：ログの「面の向きの自動判定」の行を確認し、誤っていれば --flip-winding。両面描画が必要な薄い髪やスカートは
  --force-double-sided、または GUI の「マテリアルを両面化（強制）」にチェック。
- FBX が後ろ向き：FBX タブの「向きを自動判定」（既定でオン）のままで、それでも後ろ向きなら「強制で 180° 追加回転」にチェック。
- FBX の透明が正しくない：全体が半透明・ゴーストが出るときはテクスチャの透明チャンネルを「すべて除去」に、
  レースや髪先が硬くなるときは「自動判定」か「そのまま残す」に。元のテクスチャは書き換えません。
- FileNotFoundError：Windows はパスを 260 文字までに制限しています。本ツールは自動で対処します。
  古いバージョンではファイルをドライブ直下近く（例 D:\model\）に移してから変換してください。
- MMD で PMX が読み込めない：MMD は UTF-16LE の PMX しか読めません。本ツールの出力は常に UTF-16LE です。
- PmxEditor で「アンカーデータの読み込みに失敗しました」：PmxEditor がモデルと同名の .psk をアンカーデータとして読んだためです。
  OK を押せばモデルは正常に読み込まれます。
- ドラッグ＆ドロップは Windows のみ対応。その他の OS では「参照」ボタンで選択してください。
- 設定ファイル config.json に言語 / 表示倍率 / 各オプションを保存します。削除すると既定値で作り直されます。

既知の制限：

- VRM 0.x では SpringBone 物理を出力しません。
- PMX のチェーン間の横方向の物理ジョイント（スカートに多い）は SpringBone で表現できないため捨てます。
- 乗算スフィア（.sph）は MToon に対応する項目がなく、無視します。
- テクスチャ：.dds（DXT1 / DXT3 / DXT5）は読み込めます。KTX2 / WebP は非対応で単色になります。
- FBX は英語のボーン名を保持します（MMD のモーション .vmd を使うには日本語標準名への変更が必要）。XPS には表情がありません。

著作権：
VRM の許諾情報は既定で最も制限的な「クレジット表記必須、再配布禁止、改変禁止」を書き込みます。
変換する前に、そのモデルを使う権利があるか確認してください。多くの MMD モデルは再配布を禁止しており、変換した VRM も公開配布できません。
